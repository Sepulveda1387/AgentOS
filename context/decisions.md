# Decisions Log

Durable decisions that should inform future recommendations. Add entries when a choice is made that the AI should not re-litigate without being asked.

Format:
```
## [Date] — [Short title]
**Decision:** What was decided.
**Reason:** Why.
**Impact:** What this affects going forward.
```
