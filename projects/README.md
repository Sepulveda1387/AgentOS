# Projects

Active business or personal initiatives. Each project gets its own subfolder.

## Structure

```
projects/
  <project-name>/
    README.md         # project brief, goal, status
    c-level-reviews/  # board-level reviews saved by the c-level skill
    notes/            # working notes
```

Create a subfolder here when starting a significant initiative. The AI will save c-level reviews, research, and planning artifacts into the relevant project folder.
